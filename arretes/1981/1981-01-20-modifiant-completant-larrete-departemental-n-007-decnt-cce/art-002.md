# Article 2 :
Il est prévu trois taux de cautionnement :
- pour la catégorie A, le cautionnement est de 5.000 FF ;
- pour la catégorie B, le cautionnement est de 2.500 FF ;
- pour la catégorie C, le cautionnement est de 1.500 FF.
Les personnes morales qui sollicitent l’autorisation de la catégorie D sont dispensées du cautionnement.
