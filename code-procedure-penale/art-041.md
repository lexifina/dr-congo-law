# Article 41 :
Le juge saisi de l’appel en connaître, toute affaires cessantes. Il devra statuer dans les vingt-quatre à partir de l’audience au cours de laquelle le ministère public aura fait ses réquisitions.
Si l’inculpé ne se trouve pas dans la localité où le tribunal tient audience ou s’il n’y est pas représenté par un porteur de procuration spéciale, le juge peut statuer sur pièces.
