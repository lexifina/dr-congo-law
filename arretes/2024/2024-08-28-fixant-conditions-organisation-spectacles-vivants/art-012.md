# Article 12
Toute personne physique ou morale de droit privé ou public souhaitant organiser un événement culturel doit soumettre une demande d'autorisation auprès de l'autorité compétente suivant le tableau ci-après :
Catégorie Type d’événement Type d’espace Ventilation Nombre de participants Matériel utilisé
A Type 1 Espace ouvert Naturelle Jusqu’à 500 Pas de matériel technique complexe
A Type 1 Espace semi-fermé Artificielle partielle Jusqu’à 500 Pas de matériel technique complexe
A Type 1 Espace fermé Artificielle Jusqu’à 500 Pas de matériel technique complexe
A Type 2 Espace ouvert Naturelle Jusqu’à 500 Matériel électrique simple
A Type 2 Espace semi-fermé Artificielle partielle Jusqu’à 500 Matériel électrique simple
A Type 3 Espace ouvert Naturelle Jusqu’à 500 Effets spéciaux limités, feu de bengale
B Type 1 Espace ouvert Naturelle 501-5000 Pas de matériel technique complexe
B Type 2 Espace ouvert Naturelle 501-5000 Matériel électrique complexe
B Type 2 Espace semi-fermé Artificielle partielle 501-5000 Matériel électrique complexe
B Type 3 Espace ouvert Naturelle 501-5000 Effets spéciaux, pyrotechnique
C Type 1 Espace fermé Artificielle Plus de 5000 Pas de matériel technique complexe
C Type 2 Espace fermé Artificielle Plus de 5000 Matériel électrique complexe, sonorisation
C Type 3 Espace fermé Artificielle Plus de 5000 Pyrotechnique, effets spéciaux lourds
