# Article 12 :
Les recettes exceptionnelles comprennent :
• Les amendes transactionnelles sur permis d’exploitation ;
• Les amendes transactionnelles pour non respect urbanistique ;
• La quotité produit minerval E.P.S.P. ;
• La quotité produit minerval ITM ;
• Les amendes transactionnelles santé ;
• Les amendes transactionnelles mines ;
• La quotité des produits des activités sportives ;
• Les frais d’octroi de terrain ;
• Les frais d’octroi de certificat d’enregistrement ;
• L’agrément des organisations non gouvernementale, en sigle « ONG » ;
• La taxe sur les produits agricoles ;
• La taxe sur les produits d’élevage ;
• La taxe sur les produits de pêche ;
• La taxe sur les produits de chasse ;
• La taxe sur les transferts ou transits petit et gros bétails ;
• La taxe sur domestication ou transfert de singes et perroquets ;
• La taxe sur transfert volailles et autres oiseaux sauvages ;
• La taxe sur les commissions frappant les transferts des fonds ;
• La taxe sur l’évacuation des grumes ;
• Les frais de location taxis et camions ben.
