# Article 5
La Coordination du CN-AGOA RDC est présidée par le Premier Ministre ou, en cas d’empêchement, par le Ministre pré séant membre de la Coordination.
La Coordination comprend, en outre :
- le Ministre ayant les Transports dans ses attributions : Membre ;
- le Ministre ayant l’économie nationale dans ses attributions : Membre ;
- le Ministre ayant le Plan dans ses attributions : Membre ;
- le Ministre ayant l’Agriculture dans ses attributions : Membre ;
- le Ministre ayant les Affaires Etrangères dans ses attributions : Membre ;
- le Ministre ayant la Justice dans ses attributions : Membre ;
- le Ministre ayant l’Environnement dans ses attributions : Membre ;
- le Ministre ayant les Infrastructures dans ses attributions : Membre;
- le Ministre ayant le Budget dans ses attributions : Membre ;
- le Ministre ayant les Affaires Foncières dans ses attributions : Membre ;
- le Ministre ayant l’Aménagement du Territoire dans ses attributions : Membre ;
- le Ministre ayant les Finances dans ses attributions : Membre ;
- le Ministre ayant l’Industrie et Petites et Moyennes Entreprises dans ses attributions : Membre ;
- le Ministre ayant les Ressources hydrauliques et Electricité dans ses attributions : Membre ;
- le Ministre ayant les Mines dans ses attributions : Membre ;
- le Ministre ayant les Hydrocarbures dans ses attributions : Membre;
- le Ministre ayant l’Emploi et le Travail dans ses attributions : Membre ;
- le Ministre ayant la Recherche scientifique dans ses attributions : Membre ;
- le Ministre ayant les Télécommunications, NTIC et le Numérique dans ses attributions : Membre ;
- le Ministre ayant la Santé Publique dans ses attributions : Membre;
- le Ministre ayant le Commerce Extérieur dans ses attributions : Membre ;
- le Ministre ayant la Communication dans ses attributions : Membre;
- le Ministre ayant la Formation Professionnelle dans ses attributions : Membre ;
- le Ministre ayant le Genre dans ses attributions : Membre ;
- le Ministre ayant la Pêche et l’Elevage dans ses attributions : Membre ;
- le Ministre ayant la Culture et les Arts dans ses attributions : Membre ;
- le Ministre ayant le Tourisme dans ses attributions : Membre ;
- le Ministre ayant la Jeunesse dans ses attributions : Membre ;
- le Secrétaire Général du Gouvernement : Membre ;
- deux représentants du Cabinet du Président de la République dûment mandatés : Membres ;
- deux représentants du Cabinet du Premier Ministre dûment mandatés : Membres ;
- le Président et un autre membre dûment mandaté de la Fédération des Entreprises du Congo (FEC) : Membres ;
- deux représentants de la diaspora congolaise des Etats-Unis d’Amérique: Membres ;
- deux représentants de la Société Civile : Membres.
