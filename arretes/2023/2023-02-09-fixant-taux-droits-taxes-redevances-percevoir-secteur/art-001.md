# Article 1
La Carte de résidence est un document obligatoire pour tout étranger qui séjourne dans la Province du Kongo Central pour une durée supérieure à six (6) mois ou pour tout étranger qui y est né. Elle est valide pour deux (2) ans.
Les cartes de résidence octroyées aux étrangers sont de trois (3) catégories :
 Catégorie A : les étrangers provenant et/ou originaires des pays autres qu’africains ;
 Catégorie B : les étrangers provenant et/ou originaires des pays africains autres que les pays limitrophes ;
 Catégorie C : les étrangers provenant et/ou originaires des pays limitrophes.
