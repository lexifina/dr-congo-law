# Article 2 :
Le Secteur de Bampende comprend les Groupements ci-après :
- Bakwa-Luwanda ;
- Bakwa-Lunda-Mukala;
- Bakwa-Nsamba ;
- Bakwa Nsumba ;
- Bakwa-Nyama ;
- Bakwa-Tule ;
- Bakwa-Njila ;
- Bakwa-Tunda ;
- Bakwa Lemba ;
- Bakwa-Mwangualala ;
- Bakwa-Luhombo ;
- Bakwa-Kisambo ;
- Bakwa-Muta ;
- Bena-Nsamba ;
- Bena-Ngoji ;
- Bakwa-Lunda-Kisenzela ;
- Bakwa-Lunda-Luweja ;
- Bakwa-Kitombe.
