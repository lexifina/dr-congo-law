# Article 5
La Coordination est présidée par le Premier ministre, et en cas d'absence ou d'empêchement, par le Ministre pré séant, membre de la Coordination.
Elle comprend, en outre :
- le Ministre ayant les Affaires Etrangères dans ses attributions : Membre ;
- le Ministre ayant l'Intégration Régionale dans ses attributions : Membre ;
- le Ministre ayant le Commerce Extérieur dans ses attributions : Membre ;
- le Ministre ayant la Justice dans ses attributions : Membre ;
- le Ministre ayant le Budget dans ses attributions : Membre ;
- le Ministre ayant le Plan dans ses attributions : Membre ;
- le Ministre ayant les Infrastructures dans ses attributions : Membre ;
- le Ministre ayant les Hydrocarbures dans ses attributions : Membre ;
- le Ministre ayant les Ressources Hydrauliques et l'Electricité dans ses attributions : Membre ;
- le Ministre ayant l'Emploi dans ses attributions : Membre ;
- le Ministre ayant le Genre, Famille et Enfant dans ses attributions : Membre ;
- le Ministre ayant les Finances dans ses attributions : Membre ;
- le Ministre ayant l'Economie Nationale dans ses attributions : Membre ;
- le Ministre ayant les Mines dans ses attributions : Membre ;
- le Ministre ayant les Postes, Télécommunications et NTIC dans ses attributions : Membre ;
- le Ministre ayant le Numérique dans ses attributions, Membre ;
- le Ministre ayant la Santé dans ses attributions : Membre ;
- le Ministre ayant l'Environnement dans ses attributions : Membre ;
- le Ministre ayant les Transports dans ses attributions : Membre ;
- le Ministre ayant l'Agriculture dans ses attributions : Membre ;
- le Ministre ayant la Pêche et l'Elevage dans ses attributions : Membre ;
- le Ministre ayant la Recherche Scientifique et Innovation Technologique dans ses attributions : Membre ;
- le Ministre ayant l'Industrie dans ses attributions : Membre ;
- le Ministre ayant les Petites et Moyennes Entreprises dans ses attributions : Membre ;
- le Ministre ayant le Tourisme dans ses attributions : Membre ;
- le Ministre ayant la Culture et Arts dans ses attributions : Membre ;
- le Ministre près le Président de la République ;
- deux représentants du Cabinet du Président de la République dûment mandatés, Membres ;
- un représentant du Cabinet du Premier ministre dûment mandaté, Membre.
