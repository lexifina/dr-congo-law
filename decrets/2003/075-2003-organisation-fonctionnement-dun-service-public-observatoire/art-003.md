# Article 3 :
L’Observatoire du Code d’Ethique Professionnelle a pour mission :
- d’assurer dans les milieux professionnels et auprès du public la promotion, la diffusion, la vulgarisation et le suivi du Code de conduite de l’Agent Public de l’Etat ;
- de veiller à tout instant, à la bonne application du Code et proposer aux autorités compétentes les mesures appropriées pour prévenir et sanctionner les violations des dispositions du Code ;
- de publier un rapport annuel sur l’application et l’efficacité du Code de Conduite de l’Agent Public de l’Etat.
