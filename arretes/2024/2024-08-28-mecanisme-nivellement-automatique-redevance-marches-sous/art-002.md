# Article 2
En vue de mettre en œuvre le dispositif repris dans l’article ci-dessus, un protocole d’accord est signé entre l’ARSP, les banques commerciales impliquées et les structures allocataires dans le but de transférer automatiquement vers leurs comptes respectifs, les quotités dues suivant la clé de répartition ci-dessous :
- ARSP : quotité de 0,8% sur le 1,2% ;
- FOGEC : quotité de 0,2% sur le 1,2% ;
- ANADEC: quotité de 0,1% sur le 1,2% ; et
- APROCM: quotité de 0,1% sur le 1,2%.
