# Article 3 :
Le personnel de carrière de la Direction Générale des Recettes du Maniema est réparti en trois catégories d’emplois ci-après :
A. Emplois de commandement
• Directeur ;
• Chef de Division ;
• Chef de Bureau.
B. Emplois de collaboration
• Attaché de bureau de 1ère classe ;
• Attaché de bureau de 2e classe ;
• Agent de bureau de 1e classe.
C. Emplois d’exécution
• Agent de bureau de 2e classe ;
• Agent auxiliaire de 1ère classe
• Agent auxiliaire de 2e classe ;
• Huissier.
