# Article 18
S’agissant des agents en activité, les autorités hiérarchiques compétentes pour accorder, en application de l’article 25 de la Loi n° 81-003, les congés prévus sont les suivantes :
 En ce qui concerne les agents œuvrant à l’administration centrale ;
 Le Ministre des Finances pour le Directeur Général et le Directeur Général Adjoint;
 Le Directeur Général pour les autres catégories d’agents.
 En ce qui concerne les agents œuvrant en région :
 Le Directeur Général, en ce qui concerne le Directeur régional ;
 Le Directeur Régional pour les autres catégories d’agents.
