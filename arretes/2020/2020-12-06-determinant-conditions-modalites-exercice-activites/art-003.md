# Article 3
Les professions qui concourent à l'exercice des activités de voyages, d'accueil des touristes, d'hébergement et de restauration sont, notamment :
1) Les activités d'organisation de voyages et d'accueil :
1. L'Agent de voyages ou de comptoir ;
2. Le Billettiste ;
3. L'Agent d'accueil ;
4. Le Conseiller en voyage ;
5. Le Guide touristique ;
2) Les activités d'hébergement :
1. Le Gouvernant général ;
2. Le guest relation ;
3. L'agent de réservation ;
4. Le night auditor;
5. Le réceptionniste ;
6. Le valet ou femme de chambre ;
7. Le linger;
3) Les activités de restauration :
1. Le maître d'hôtel ;
2. Le commis de restaurant ;
3. Le commis de bar;
4. Le commis de cuisine ;
5. Le pâtissier ;
6. Le boulanger ;
7. L'order-taker ;
8. Le cuisinier.
