# Article 328
Des demandes d’octroi en instance à la date de la promulgation du présent Code Les requérants qui ont des demandes d’octroi des droits miniers et/ou de carrières en instance à la date de la promulgation du présent Code doivent les reformuler conformément aux dispositions du présent Code dans un délai de trois mois à compter de l’entrée en vigueur du Règlement Minier. Passé ce délai, ces requérants perdent leur droit de priorité.
