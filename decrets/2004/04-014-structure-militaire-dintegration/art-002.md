# Article 2 :
La Structure Militaire d’Intégration a pour mission d’arrêter et de mettre en œuvre les modalités d’intégration, notamment :
1. La sensibilisation ;
2. Le regroupement ;
3. L’identification ;
4. La sélection ;
5. Le cantonnement ;
6. Le brassage avec recyclage et/ou formation.
