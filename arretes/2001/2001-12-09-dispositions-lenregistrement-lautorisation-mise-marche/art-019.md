# Art. 19. — Les dispositions du présent arrêté s’appliquent également aux spécialités pharmaceutiques.
Par spécialité pharmaceutique, on entend tout médicament préparé à l’avance, mis sur le marché sous une dénomination spéciale et sous un conditionnement particulier.
Pour la dénomination d’une spécialité, le fabricant peut donner n’importe quel nom, sauf:
• le nom qui est employé dans le langage courant pour désigner les drogues;
• le nom se rapprochant d’un nom de spécialité déjà connu;
• le nom d’organe ou de maladie ou d’une action thérapeutique avec lequel le produit proposé n’a pas de rapport.
