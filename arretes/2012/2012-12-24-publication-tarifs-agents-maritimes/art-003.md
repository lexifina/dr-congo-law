# Article 03 :
Sont supprimés, tous les tarifs et rémunérations portant sur les actes et les prestations ci-après :
- Établissements master/LTO ;
- Annulation master/LTO ;
- Carte d’entrée container ;
- Note de fret ;
- Ventes des imprimés ;
- Branchement clip on ;
- Frais administratifs et opérationnels ;
- Frais de dépotage ;
- Frais de laissez suivre.
