# Article 29 :
L’Agent Public de l’Etat qui, intentionnellement, par négligence ou imprudence, enfreint ses devoirs professionnels ou se place dans un cas d’incompatibilité est passible d’une sanction disciplinaire conformément aux dispositions du Code, du Statut, du Règlement d’administration ou de la Convention Collective auxquels il est soumis, indépendamment, des peines prévues par le Code Pénal Congolais.
