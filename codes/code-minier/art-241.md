# Article 241
Du taux de la redevance minière Le taux de la redevance minière est de 0,5% pour le fer ou les métaux ferreux, 2% pour les métaux non ferreux, 2, 5% pour les métaux précieux, 4% pour les pierres précieuses, 1% pour les minéraux industriels, les hydrocarbures solides et autres substances non citées, et 0% pour les matériaux de construction d’usages courants.
