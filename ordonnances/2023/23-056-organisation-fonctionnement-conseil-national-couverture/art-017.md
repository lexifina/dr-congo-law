# Article 17
Le Personnel administratif est constitué comme suit :
- Un Secrétaire administratif ;
- Deux Opérateurs de saisie ;
- Un Agent chargé de la logistique (intendant) ;
- Un Agent chargé du courrier ;
- Deux Agents chargés du protocole ;
- Deux Hôtesses ;
- Un Huissier ;
- Deux Chauffeurs.
