# Article 7 :
La Commission Opérations Spécifiques d’Intégration est chargée de :
1. concevoir et diffuser le message en rapport avec les termes de référence édictés ;
2. choisir les supports médiatiques ;
3. assurer toutes les opérations d’identification;
4. cantonnement des hommes ;
5. recyclage et/ou formation ;
6. sélection ;
7. brassage.
