# Article 4 :
Elle poursuit les objectifs spécifiques ci-après :
- Préparer les plans d’action pour le financement des projets ;
- Exécuter le plan d’action en respect des modalités de mise en oeuvre convenues avec le PMLS ;
- Suivre les procédures de passation des marchés exigées par la Banque mondiale ;
- Collecte les données objectivement vérifiables sur les indicateurs tels que définis dans le cadre logique pour le suivi et l’évaluation ;
- Assister aux réunions de l’avancement des activités organisées par le PNMLS tous les trois mois ;
- Préparer les rapports annuels de fin d’exécution du plan d’action.
