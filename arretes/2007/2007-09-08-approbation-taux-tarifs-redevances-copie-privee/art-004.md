# Article 4 :
La redevance pour copie privée est versée à la SONECA avant la mise en circulation de ces supports et/ou appareils dans le commerce ou pour une activité non lucrative, elle est fixée de la manière suivante :
I. 0,01 $US l’unité pour les supports analogiques ;
II. 0,20 $US l’unité pour les supports numériques ;
III. 0,30 $US l’unité pour les supports numériques intégrés ;
IV. 10% sur prix d’achat par unité pour les appareils.
