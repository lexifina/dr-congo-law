# Article 19
Les délégués visés à l'article précédent proviennent des institutions, Ministères et organismes sectoriels suivants :
- Présidence de la République (02) ;
- Primature (02) ;
- Ministère ayant l'Intérieur et la Sécurité dans ses attributions (01) ;
- Ministère ayant la Défense Nationale dans ses attributions (01) ;
- Ministère ayant l'Urbanisme et l'Habitat dans ses attributions (02) ;
- Ministère ayant la Décentralisation dans ses attributions ;
- Ministère ayant les Affaires Foncières dans ses attributions (02) ;
- Ministère avant les Finances dans ses attributions (01) ;
- Ministère ayant le Budget dans ses attributions (01);
- Ministère ayant les Infrastructures et les Travaux Publics dans ses attributions (01) ;
- Ministère ayant l'Environnement dans ses attributions (01) ;
- Ministère ayant l'Aménagement du territoire dans ses attributions (01).
- Ministère ayant les Transports et les Voies de Communication dans ses attributions (01) ;
- Ministère ayant les Ressources Hydrauliques et l'Electricité dans ses attributions (01) ;
- Ministère ayant le Numérique dans ses attributions (01) ;
- Ministère ayant la Culture et les Arts dans ses attributions (01) ;
- Agence Congolaise pour la Promotion Immobilière (01) ;
- Fonds National de l'Habitat (01) ;
- Secrétariat général du Gouvernement (1) ;
- Ville de Kinshasa (1).
