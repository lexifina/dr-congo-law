# Article 3 :
Le CMP est composé des membres ci-après :
- le Ministre ayant le Budget dans ses attributions ;
- le Ministre ayant les Infrastructures, Travaux publics et Reconstruction dans ses attributions ;
- le Ministre ayant la Santé Publique dans ses attributions ;
- le Ministre ayant les Finances dans ses attributions ;
Le Secrétaire général à la Santé Publique assure le secrétariat du Comité Multisectoriel de Pilotage, assisté par le coordonnateur du Groupe Technique de Coordination (GTC).
