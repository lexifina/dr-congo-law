# Article 22 : Des personnes habilitées à présenter les opérations de microassurance
Sont autorisées à présenter des opérations de microassurance auprès du public, à condition d’obtenir une carte professionnelle délivrée par l’Autorité de Régulation et de Contrôle des Assurances, les personnes suivantes ou leurs mandataires :
1. Les courtiers ;
2. Les agents généraux ;
3. Les personnes physiques mandataires ;
4. Les banques, la poste et les établissements financiers ;
5. Les institutions de microfinance ;
6. Les mutuelles de santé ;
7. Les coopératives et groupements agricoles ;
8. Les organisations non gouvernementales ;
9. Les agences de développement ;
10. Les associations et tontines ;
11. Les fonds funéraires ;
12. Les syndicats ;
13. Les sociétés et les distributeurs de téléphones mobiles ;
14. Les responsables sanitaires ;
15. Les chaînes de distribution alimentaires ;
16. Les sociétés à forts potentiels d’affiliation ;
17. Les communautés religieuses constituées conformément à la législation en la matière ;
18. Les assurtech et les fintech.
