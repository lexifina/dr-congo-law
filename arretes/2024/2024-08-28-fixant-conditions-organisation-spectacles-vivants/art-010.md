# Article 10
Les événements sont classés en fonction du type d'espace dans lequel ils se déroulent.
A savoir :
a) Espace ouvert : tout type d'évènements se déroulant en plein air où la ventilation est naturelle ;
b) Espace semi-fermé : tout type d'événements se déroulant dans des espaces partiellement couverts ou avec une ventilation artificielle partielle ;
c) Espace fermé : tout type d'événements se déroulant dans des lieux entièrement clos à l'instar de salles, stades couverts où la ventilation est entièrement artificielle ;
d) Espace dans les zones à risques : tout type d'évènements se déroulant dans des régions volcaniques, sur les rives, sur les bateaux...
