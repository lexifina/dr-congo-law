# Article 17
Les grades correspondants aux emplois prévus à l’article 16 sont hiérarchisés et établis.
Ils sont repartis en:
1. Catégorie A, hauts fonctionnaires:
- Secrétaire Général;
- Directeur Général ;
- Directeur.
2. Catégorie B, cadres supérieurs:
- Chef de Division;
- Chef de Bureau.
3. Catégorie C, agents de collaboration :
- Attaché d’Administration de 1ère Classe;
- Attaché d’Administration de 2ème Classe;
- Agent d’Administration de 1ère Classe.
4. Catégorie D, agents d’exécution:
- Agent d’Administration de 2ème Classe;
- Agent Auxiliaire de 1ère Classe;
- Agent Auxiliaire de 2ème Classe ;
- Huissier.
Le niveau de recrutement, les échelles indiciaires, les indices de traitement et le plan de déroulement de la carrière pour chaque catégorie d’emplois prévus à l’article précédent sont fixés par règlement d’administration.
