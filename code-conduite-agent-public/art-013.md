# Article 13 :
Dans son domaine de compétence, l’Agent Public de l’Etat a le devoir de fournir au public les informations qui lui sont destinées. Celles-ci ne doivent pas faire l’objet de monnayage.
Il lui est cependant interdit de porter atteinte au secret professionnel tel que prévu par l’article 73 du Code Pénal, livre II.
