# Article 3
Peuvent être importés sans considération des limites d’âge contenues dans le Décret :
- les cycles, les cyclomoteurs et les motocycles ;
- les remorques, les semi-remorques et les remorques légères ;
- les véhicules sur rails ou tramways ;
- les véhicules poids lourds équipés des ponts avant motrices de type 4x4, 6x6 et 8x8 ;
- les tracteurs agricoles ;
- les engins de génie civil ;
- les engins de génie sanitaire.
