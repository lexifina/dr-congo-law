# Article 4 :
Sont considérés comme établissement de loisirs notamment les cercles privés, les casinos, les night-clubs, les salles de fêtes, les salles de jeux, les salles polyvalentes, les hôtels-bars, les snack-bars, la machine à sous, les nintendo, les playstations, les randonnées fluviales, parcs d’attraction, les lounge-bars, les billards ou tout endroit où sont pratiqués les jeux de toutes catégories.
