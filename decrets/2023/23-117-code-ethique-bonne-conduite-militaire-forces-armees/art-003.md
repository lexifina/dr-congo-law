# Article 3
Le militaire doit afficher, en tout temps, un comportement caractérisé par les valeurs ci-après :
- L’abnégation ;
- La bravoure ;
- Le courage ;
- Le devoir ;
- La discipline ;
- L’esprit d'équipe ;
- La fidélité aux institutions légalement établies ;
- L’honneur ;
- L’intégrité ;
- la loyauté ;
- Le patriotisme ;
- le professionnalisme ;
- la redevabilité ;
- Le respect des droits humains ;
- La tolérance.
