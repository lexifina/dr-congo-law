# Article 2 :
Le Fonds de Promotion du Tourisme est constitué des redevances ci-après :
• Redevance sur les prix des nuitées ;
• Redevance sur les prix des repas et boissons ;
• Redevance sur les billets d'avion réseau domestique ;
• Redevance sur les billets d'avion réseau international ;
• Redevance sur les voyages lacustres ;
• Redevance sur les voyages fluviaux ;
• Redevance sur les voyages maritimes ;
• Redevance sur les voyages ferroviaires ;
• Redevance sur les voyages routiers.
