# Article 223
Du bénéfice du régime applicable au titulaire des titres miniers Jouissent également du bénéfice de l’ensemble du régime fiscal et douanier prévu par le présent Code : a) Les sociétés affiliées exerçant des activités minières prévues dans le présent Code ; b) Les sous-traitants exerçant des activités minières qui entrent dans le champ d’application du présent Code et qui résultent exclusivement des contrats conclus avec le titulaire.
