# Article 168
Des biens susceptibles d’hypothèques Sont susceptibles d’hypothèques au sens du présent Code : a) le Permis d’Exploitation, le Permis d’Exploitation de Rejets, le Permis d’Exploitation de Petite Mine et l’Autorisation d’Exploitation de Carrières Permanente, en tout ou en partie ; les immeubles par incorporation situés dans le Périmètre d’exploitation minière, notamment les usines, les installations et les machines construites pour la concentration, le traitement et la transformation des substances minérales contenues dans les gisements ou dans les gisements artificiels ; b) les immeubles par destination affectés à l’exploitation minière.
