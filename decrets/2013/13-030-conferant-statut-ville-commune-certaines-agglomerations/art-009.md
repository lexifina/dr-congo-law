# Article 9
Le statut de Commune est conféré aux agglomérations suivantes de la Province du Maniema :
1) Cité de Kabambare - Commune Kabambare ;
2) Cité de Wamaza - Commune de Wamaza ;
3) Cité de Kailo, - Commune de Kailo ;
4) Agglomération de Lubelenge - Commune de Lubelenge ;
5) Agglomération de Misabanga - Commune de Misabanga ;
6) Cité de Kipaka - Commune de Kipaka ;
7) Agglomération de Bikenge - Commune de Bikenge ;
8) Agglomération de Samba - Commune de Samba ;
9) Agglomération de Kahonda - Commune de Kahonda ;
10) Agglomération de Luekachi - Commune de Luekachi ;
11) Cité de Kibombo - Commune de Kibombo ;
12) Agglomération de Likeri - Commune de Likeri ;
13) Cité de Tshamaka - Commune de Tshamaka ;
14) Agglomération de Mungele - Commune de Mungele ;
15) Cité de Pangi - Commune de Pangi ;
16) Agglomération de Kampene - Commune de Kampene ;
17) Agglomération de Kama - Commune de Kama ;
18) Agglomération de Kibeleketa - Commune de Kibeleketa ;
19) Agglomération de Kowe - Commune de Kowe.
